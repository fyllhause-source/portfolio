| Файл | Что это |
|---|---|

| `resume.pdf` | Резюме на одну страницу A4 для откликов и ATS. Собирается из `resume.html` |

## Позиционирование

- Целевые отрасли: финтех и другие непромышленные продукты. Опыт в IPS описан через тип задач (аналитика, сложные таблицы, взаимодействие), а не через отрасль.
- Опыт начинается с 09.2021 (SimbirSoft). Фриланс 2018–2021 в резюме не указывается.
- Контакты, опыт и образование перенесены из прошлой версии резюме в Notion. Копия прошлой версии лежит в Notion отдельной страницей «Архив».
- Портфолио пока приватное. Ссылка «Портфолио» в резюме ведёт на страницу в Notion.

## Обложки и экраны кейсов

- Финтех-кейсы: обложки `assets/img/covers/bnpl.jpg`, `bank.jpg` и экраны в `assets/img/fintech/` экспортированы из Figma (файл «Обложки для кейсов»). Название банка-клиента и BNPL-сервиса размыто.
- IPS-кейсы: обложки `rakurs.jpg`, `gantt.jpg`, `ds.jpg` собираются из скриншотов скриптом:

```bash
NODE_PATH=$(npm root -g) node tools/build-covers.js
```

Все обложки в формате 16:9.

## Как пересобрать PDF

```bash
NODE_PATH=$(npm root -g) node -e "
const { chromium } = require('playwright');
(async () => { const b = await chromium.launch(); const p = await b.newPage();
await p.goto('file://' + process.cwd() + '/resume.html', {waitUntil:'networkidle'});
await p.pdf({path:'resume.pdf', format:'A4', preferCSSPageSize:true, printBackground:true}); await b.close(); })();"
```

## На каких стандартах основана структура

**Резюме**
- 1–2 страницы. Позиция и домен в заголовке, 3–4 строки о себе.
- Пункты опыта строятся как «действие → масштаб → результат». Цифры только подтверждённые.
- Навыки сгруппированы, в тексте есть ключевые слова для ATS: Product Discovery, Enterprise UX, Design System, Usability Testing.
- Первое лицо, без «я как дизайнер…». Ссылка на портфолио в шапке.

**Кейс**
- 3–4 глубоких кейса вместо галереи экранов: один с исследованием, один с доработкой продукта, один с дизайн-системой.
- Структура: контекст и роль → проблема → что я сделал → ключевые решения и почему → результат → как проверить.
- Если метрик нет, это прямо сказано и показан план замеров. Выдуманные проценты не добавляются.
- NDA: демо-данные, скрытые адреса и имена.
